HLL // COMMAND CENTER — PUBLICATION

Je Supabase-project is al aangemaakt. De database bevat de clan-tabellen.

1. Open Supabase → SQL Editor.
2. Open het bestand: supabase/PRODUCTION-FIX.sql
3. Kopieer alles en klik RUN.
4. Daarna is de database klaar voor de webapp.

5. Publiceer de map hll-command-center-v1 via GitHub + Vercel.
6. In Vercel voeg je deze Environment Variables toe:
   VITE_SUPABASE_URL = jouw Supabase Project URL
   VITE_SUPABASE_PUBLISHABLE_KEY = jouw Supabase publishable key
7. Redeploy.

Belangrijk: zet NOOIT een Supabase secret/service_role key in Vercel of in de frontend.

Daarna:
- open de website
- CREATE ACCOUNT
- bevestig je e-mail als Supabase dat vraagt
- log in
- maak je clan aan

De app gebruikt daarna gedeelde clouddata via Supabase en live synchronisatie voor het gezamenlijke clan-workspace.
